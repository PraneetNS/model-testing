# ML Guard Features

ML Guard provides end-to-end governance and safety checks for modern AI.

## Core Pillars
1. **Governance & Auditing**:
   - Automated compliance generation and SHAP explainability.
   - Comprehensive model report cards mapping risks to standardized thresholds.

2. **Fairness Analytics**:
   - Detect biases using Statistical Parity Difference, Disparate Impact, and Equal Opportunity metrics.
   - Deep group breakdown of precision/recall performance based on sensitive demographics.

3. **Behavior & LLM Guardrails**:
   - Deep vulnerability scanning via adversarial prompt injection simulation.
   - Toxicity, robustness/stability checks, and grounding fidelity (RAG) monitoring.
   - Scenario testing including boundary detection and out-of-distribution tracking.

4. **Monitoring & Streaming Drift**:
   - WebSocket streaming ingestion to capture real-time inference drift (Rolling PSI/JSD).
   - Alert notifications across pipelines immediately flagging data shift anomalies.

5. **AI Advisory Copilot**:
   - Interact with audit results utilizing integrated LLM insight generation to explain complex ML failures directly to non-technical stakeholders.
