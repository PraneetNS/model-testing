# Plugins & Connectors

ML Guard emphasizes out-of-the-box system connectivity for Data Engineers and ML Ops engineers.

## Data Connectors
- **Enterprise Lakes**: Configured base-support for Snowflake, AWS S3, GCP BigQuery, Google Cloud Storage, and Azure Blob environments securely isolated using encrypted tokens.
- **Public Datasets**: Native `Kaggle`, `OpenML`, and Computer Vision `Roboflow` ingestion capabilities ensuring standard benchmark evaluation can occur instantly in one click.

## Notifications
- **Microsoft Teams & Slack**: Hook up incoming webhooks per-model to guarantee stakeholders get instantaneous critical incident alerts regarding security bypasses, fairness violations, or severe conceptual data drift metrics.
